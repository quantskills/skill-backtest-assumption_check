# 数据来源与边界

> 对齐 QUANTSKILLS 社区规则 §8：**本 skill 不附带任何市场数据**，审计判定基于使用者提供的材料。

## 数据从哪来

| 材料 | 来源 | 说明 |
|---|---|---|
| 回测代码 / 策略代码 / 研究报告 | 使用者提供 | 审计对象 |
| `signal`（`[date × symbol]` 浮点） | 使用者提供，或经 pandadata 导出 | 可选 |
| 行情面板 `panel`（OHLCV，建议含涨跌停、停牌标记） | 使用者提供，或经 pandadata 导出 | 可选 |
| 历史成分 / 生命周期（幸存者轴） | pandadata 指数成分接口 / 使用者文件 | 可选 |
| `assumptions.json` | 使用者填写或默认生态基线 | 可选 |

## Pandadata 如何供数（推荐路径）

- 行情面板：`panda_data.get_stock_daily(...)` 导出为 CSV / Parquet，作为 `--panel` 输入。
- 指数历史成分：`panda_data` 指数成分接口，用于 `survivorship` 探测器重建历史池。
- 涨跌停 / 停牌标记：由行情接口字段或使用者补充列提供。
- 注意：`pandadata` 与 `panda_data` 为同一数据服务的两种写法，接口能力以当前文档为准。

## 边界声明

- **本 skill 不做行情拉取、不做回测重跑**：只有使用者给数据时才能做数据级验证。
- **数据合法性与许可由使用者负责**：本 skill 不验证数据来源合法性。
- **探测器输入缺失 → 对应轴降级为 INFO（证据不足）**，并在报告中列出缺失材料。
- **合成数据自检**（`scripts/self_test.py`）仅用于演示与验证 skill 能力，不代表任何真实市场结论。
