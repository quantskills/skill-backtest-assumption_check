# 修复方案库

> 每个轴的「标准修复动作」。审计者按具体缺陷选用，并写出**修复后如何验证**（复检动作）。
> 目标：让用户拿到清单就能改，改完能证明改对了。

## 轴 1：成交时点与未来函数

- 信号统一 `shift(1)`，禁止同日成交。
- 成交价用 `open[T+1]`（对齐生态基线），卖出同理。
- 前视隔离：信号计算只允许用到 T 日及以前数据；T+1 开盘价用于成交。
- **复检**：跑 `detectors/execution_timing.py` 前缀回放，确认 close→close 与 T+1 开盘两条曲线不再重合。

## 轴 2：交易成本

- 双边成本从毛收益中扣减。A 股参考起点：佣金 ≈ 2.5~3bp / 边，印花税卖出 5bp，滑点另计；生态基线双边 15bp。
- 对成本做敏感性分析：成本 × 0.5 / ×1 / ×2 下 Sharpe 与净值的变化。
- **复检**：`detectors/cost_model.py` 反推隐含成本，应接近假设值。

## 轴 3：涨跌停与停牌

- 买入日标记涨停一字板（买不进）→ 剔除该仓位（不成交）。
- 卖出日标记跌停一字板（卖不出）→ 顺延或按规则强制次日卖。
- 停牌日持仓：保留市值、不计收益，或按规则处理。
- **复检**：`detectors/price_limits.py` + `suspensions.py` 确认持仓清单里不再出现不可成交日。

## 轴 4：幸存者偏差

- 按披露日快照重建历史股票池（含已退市、已停牌标的）。
- 退市股：收益按真实路径计算至退市日，之后归零或出池。
- 统计「退市收益缺口」并披露。
- **复检**：`detectors/survivorship.py` 输出的缺失比例应接近 0（扣除合理时点差）。

## 轴 5：参数自由度与多重比较

- 记录全部试验（参数网格 + 结果），披露试验次数 N。
- 计算 Deflated Sharpe 或期望最大 Sharpe（`detectors/parameter_freedom.py`）。
- 预留 holdout / 独立样本外区间，只在样本外确认后才算数。
- **复检**：报告校正后 Sharpe；样本外结果独立复算。

## 轴 6：数据对齐与复权

- 统一复权口径（前复权），禁止混用。
- 财报字段用「发布日 announce_date」而非「报告期 period_date」（point-in-time）。
- join 键强制日期对齐，杜绝未来行。
- **复检**：`detectors/data_alignment.py` 复权跨除权日连续。

## 轴 7：换手与容量

- 权重序列持久化，算单边换手并计入成本。
- 篮子成交额 / 成分股 ADV：占比超 5% 的标的视为容量受限，单独披露。
- 冲击成本模型：占比越高，成本越高。
- **复检**：`detectors/turnover_capacity.py` 输出的换手与占比，确认与成本建模一致。

## 轴 8：基准与超额

- 选可比基准（A 股多头 → 相应宽基指数；行业策略 → 行业基准）。
- 超额口径一致：同区间、同频率、含成本。
- 有风格暴露时补充多因子剥离后的超额归因。
- **复检**：基准序列与策略同源可比，超额曲线可复算。

## 轴 9：报告透明度

- 固定随机种子、数据版本、参数表、样本区间。
- 附「复现步骤」：数据来源 → 参数 → 回测 → 结果，他人可重算。
- 披露已知限制与假设清单。
- **复检**：按报告步骤重算，关键数字一致。
